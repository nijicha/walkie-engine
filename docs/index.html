Docs/Installation

Installation

Install the walkie engine and the walkie plugin, then ask Claude Code for a narrated video of your change. You don't need the Mac app.

Two installs. The engine is a command line tool from Homebrew (nijicha/walkie-engine). The skill, the subagent and the MCP server are a Claude Code plugin from the nijicha/skills marketplace. They update separately.

How it works

Walkie has two halves. The skill is text that tells Claude what to do. The engine is code on your Mac that does it. Claude sits in between: it reads the skill, then uses the engine's tools.

The skill can't run anything by itself. Every action reaches the engine through the MCP server.

The parts

SkillSKILL.md · references/
Instructions Claude reads: the steps, the two checkpoints, how to write Thai narration, and which layer to change for each kind of request.
Subagentagents/walkie.md
Claude on Sonnet in a fresh context. Your main session hands it a short brief, so a long conversation doesn't pay for the video.
MCP serverengine/mcp/server.ts
The only way into the engine. Its 13 tools include start, storyboard, record, revoice and rerender.
Recorder + overlayTypeScript
Playwright drives your app and records the screen. The overlay (captions, highlight box, cursor, cards) is drawn afterwards in Chromium from a log of events.
wtRust · engine/bin/wt
Speaks the Thai narration, lays the overlay and the voice over the recording to make the MP4, and makes the contact sheet.
Profiletheme.json · voice.json · NOTES.md
Your team's look and voice, and how to start your app.
LibraryApplication Support/…/videos
Each finished video with its layers, ready to revoice or rerender.

One video, start to finish

  1. You ask for a walkie of a change. Claude passes a brief to the subagent.
  2. The subagent writes a storyboard: one scene per step, with a caption and a line of narration. The engine voices each line and flags any that are too fast or choppy.
  3. Checkpoint 1. You approve the storyboard.
  4. The subagent writes a Playwright spec for the scenes, with a check in every scene, so a broken feature fails the recording instead of making a wrong video.
  5. The engine records your app. While it records, it draws nothing on the page; it only logs when each caption, highlight and cursor move happens.
  6. The overlay is drawn from that log, frame by frame, in the profile's look. wt combines the page, the overlay and the voice into walkie.mp4.
  7. wt makes a contact sheet: two frames per narration line, plus a check for flashes.
  8. Checkpoint 2. You approve the contact sheet and the MP4.

Why changes don't need a new recording

A video is kept as separate layers, so each kind of change rebuilds only its own layer.

LayerChanges when youRebuilt by
VoiceReword a narration linerevoice
TextReword a caption or cardtexts, rerender
OverlayChange colors, fonts, sizes or the logorerender
PageChange steps, order, pauses, zoom or video sizea new recording

Install

  1. Install the engine

    Install walkie with Homebrew, then run setup once. Setup downloads the engine's own Chromium and the Thai voice model to ~/.cache/walkie.

    Terminal
    brew install nijicha/tap/walkie
walkie setup

  2. Install the plugin

    In Claude Code, install the walkie plugin. It brings the skill, the walkie subagent and the MCP server, which runs the engine you just installed.

    Claude Code
    /plugin install walkie --marketplace nijicha/skills

    On Claude Code older than 2.1.275, add the marketplace first: /plugin marketplace add nijicha/skills, then /plugin install walkie@nijicha-skills.

  3. Check that it works

    Check the engine version, then record the smoke test. It records a static page, so you don't need an app.

    Terminal
    walkie version
walkie smoke

    Restart Claude Code and open /mcp: plugin:walkie:walkie should be connected. Each walkie starts by printing Engine: walkie <version>.

  • Choose a profile

    A profile holds your team's look and voice: colors, fonts, cards, voice settings, a lexicon, and notes on how to start your app. The built-in default works without any setup. For a team look, clone the team's profile repo:

    Terminal
    git clone <profile repo> ~/.config/walkie/profiles/<name>

    No team profile yet? Ask Claude “Make a walkie profile for this repo.” It asks one question at a time and writes only what differs from default. To see every state of a profile on a sample page:

    Terminal
    walkie preview <name> preview.html && open preview.html

  • Make your first walkie

    Open Claude Code in your app's repo and ask in plain words. Name the PR or ticket, what changed, and how to start the app.

    Claude Code
    Make a walkie of PR #482: guests can now edit the name on their ticket.
The app starts with bin/dev at http://localhost:3000.

    Claude hands the job to the walkie subagent, which runs on Sonnet in a fresh context. It stops twice for your answer:

    Write

    Storyboard: one scene per step, Thai narration checked for pace

    You approve

    The storyboard table, then the contact sheet and MP4

    Hand over

    MP4 path, length, scenes, and any bug it found

    Finished videos go to ~/Library/Application Support/walkie/videos/<repo>--<name>/. Set WALKIE_HOME to keep them somewhere else.

    • Everything without the Mac app

    The Mac app is a window onto the same library. Everything it does, you can ask Claude to do instead.

    In the Mac appAsk ClaudeMCP tool
    Browse the library“List my walkies”list
    Edit a caption or card“Change caption 2 to …”texts, rerender
    Edit a narration line“Say clip 3 more slowly”revoice
    Look & voice editorEdit the profile, then “rerender it”rerender
    Copy PR text“Give me the PR text”pr_text

    None of these record again. A change of steps, order, page or timing does: ask for a new recording.

    Voices and languages

    The voice is set in the profile's voice.json. engine picks the speech engine and language the language. Today there is one engine, MakHam, and it speaks Thai.

    profiles/<name>/voice.json
    {
  "engine": "makham",
  "language": "th",
  "model": "makham_female",
  "speed": 1.2
}
    EngineLanguagesModelsStatus
    makhamThaimakham_female (natural), paradee (15× faster, for drafts)AVAILABLE
    More enginesEnglish and other languages—PLANNED

    A new engine will plug in behind the same two fields, so a profile switches language by changing engine and language. Recordings, captions and the look stay the same.

    Update

    The engine and the plugin update separately. Upgrade the engine first: a newer skill refuses to start on an older engine and tells you to upgrade. Restart Claude Code after both.

    Terminal
    brew upgrade walkie
    Claude Code
    /plugin marketplace update nijicha-skills

    Chromium and the voice model stay cached in ~/.cache, so an upgrade doesn't download them again.

    Troubleshooting

    You seeDo this
    plugin:walkie:walkie fails to connectThe engine isn't installed or isn't on your PATH. Run walkie version in a terminal; if it fails, do step 1.
    The walkie engine is …, older than this skill needs, or Claude reports an unknown min_engineRun brew upgrade walkie, then restart Claude Code.
    engine packages missing: run … setupRun walkie setup.
    The voice model downloads every timeSomething clears ~/.cache/walkie. Set WALKIE_TTS_DATA to a folder that stays.
    The recording stuttersRecording is real time. Heavy steps wait in one queue for the whole machine; close other heavy work while it records.
    Something elseOpen an issue on nijicha/walkie-engine with the output of walkie version and the error.
