Installation

Requirements

  • A Mac with Apple Silicon
  • Homebrew
  • Claude Code

Install

  1. Install the engine

    Terminal
    brew install nijicha/tap/walkie
walkie setup

  2. Install the plugin

    Claude Code
    /plugin install walkie --marketplace nijicha/skills

    On Claude Code older than 2.1.275, run /plugin marketplace add nijicha/skills, then /plugin install walkie@nijicha-skills.

  3. Check that it works

    Terminal
    walkie version
walkie smoke

    Restart Claude Code and open /mcp. plugin:walkie:walkie should be connected.

Update

Upgrade the engine first, then the plugin, then restart Claude Code.

Terminal
brew upgrade walkie
Claude Code
/plugin marketplace update nijicha-skills

Troubleshooting

You seeDo this
plugin:walkie:walkie fails to connectRun walkie version. If it fails, do step 1 again.
The walkie engine is …, older than this skill needsRun brew upgrade walkie, then restart Claude Code.
engine packages missing: run … setupRun walkie setup.
Something elseOpen an issue on nijicha/walkie-engine with the output of walkie version and the error.
